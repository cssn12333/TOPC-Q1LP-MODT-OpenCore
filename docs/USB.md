# USB实测映射

控制器下共观测17条有效逻辑通道；按用户选择保留15条，XhciPortLimit关闭。

| 通道 | 保留 | 说明 |
|---|---|---|
| HS01–HS09 | 是 | 全部已测USB2；HS01/02对应物理口暂仅USB2 |
| HS11 / HS12 | 是 | 手机、存储等实测USB2；原图缺HS12影响手机RNDIS |
| HS13 | 是 | AX200蓝牙内置口，UsbConnector=255 |
| SS03 / SS04 / SS09 | 是 | 三组已实测SuperSpeed |
| SS01 / SS02 | 否 | 为保留所有已测USB2口及蓝牙/手机而舍弃 |
| HS10、HS14–16、其他SS | 否 | 没有足够实际设备测试依据 |

HS11/12按USB2连接器处理；HS1–9及保留SS按USB3处理。USB-C双面没有完整专项验证。
port-count=0x19表示最大端口索引25，不是启用25个端口；有效映射数是15。
HS05/06/07/08未将推测的SS伴生口当成已验证高速口。不要声称所有物理口都支持USB3。
Windows USBToolBox/tool 0.2发现历史结合macOS IOReg校对；公开不含原始设备序列号历史。
更换BIOS/板修订应重新测试USB2和USB3两种设备；确认蓝牙对应口仍为内部255。
